
# COS 201 - Week 3 Practical Submission

## Student Information
Course: COS 201 - Computer Programming I
Week: 3
Topic: Variables, Data Types, Expressions and Input/Output

## Programs Submitted

### 1. SimpleCalculator.java
A program that performs addition, subtraction, multiplication and division of two numbers.

### 2. AverageCalculator.java
A program that calculates the average of three numbers.

### 3. ItemCost.java
A program that calculates the total cost of items based on price and quantity.

## How to Compile and Run

Make sure Java JDK is installed.

To compile:
javac SimpleCalculator.java

To run:
java SimpleCalculator

For the other programs, use:

javac AverageCalculator.java
java AverageCalculator

javac ItemCost.java
java ItemCost

## Conclusion
These programs demonstrate the use of variables, data types, expressions, and input/output in Java programming.
